## How ProppFrexx ONAIR Sits

ProppFrexx ONAIR does not replace the mixer surface, the playlist folder, or the overlay files you already operate. It sits beside them as a named air desk for one job: which overlay is live, which playlist still matches the live mixer, and what the next person should read while the hour is already running.
